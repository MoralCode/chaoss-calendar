Subscribe to the WG calendar

The working group publishes its meeting schedule as a live iCalendar feed. Subscribe once and every schedule change — moved meetings, new sessions, cancellations — lands in your calendar on its own.

Both addresses serve the same feed. webcal:// is just a signal to your browser to hand the link to a calendar app; every app below also accepts the plain https:// form. The address redirects once before serving the file — all major clients follow redirects, so paste it as-is.

Subscribe, don't import

Opening a downloaded .ics file adds a one-time snapshot: the events land in your calendar, but nothing updates afterward. Subscribing registers the feed's address with your calendar app, which then re-checks it on a schedule. Everything below subscribes.

Google Calendar web

  1. Open calendar.google.com and find Other calendars in the left sidebar.
  2. Click the + next to it and choose From URL.
  3. Paste the https address and click Add calendar. The feed appears under Other calendars.

Google re-checks external feeds roughly once a day, so changes can take up to 24 hours to appear.

Official guide: Google Calendar Help — use a link to add a public calendar

Apple Calendar macOS

  1. In Calendar, choose File → New Calendar Subscription…
  2. Paste either address and click Subscribe.
  3. In the sheet that follows, set Auto-refresh (from every 5 minutes up to weekly) and click OK.

Official guide: Apple Calendar User Guide

iPhone & iPad iOS / iPadOS

  1. Open Settings → Calendar → Accounts and tap Add Account.
  2. Choose Other → Add Subscribed Calendar.
  3. Paste the https address, tap Next, then Save.

Tapping a webcal:// link on a web page also offers to subscribe directly.

Official guide: iPhone User Guide

Outlook web · Microsoft 365

  1. Sign in to Outlook on the web and switch to the Calendar view.
  2. Click Add calendar → Subscribe from web.
  3. Paste the https address, give the calendar a name, and click Save.

Official guide: Microsoft Support — import or subscribe to a calendar in Outlook.com or Outlook on the web

Thunderbird desktop

  1. Open the Calendar tab and choose New Calendar…
  2. Pick On the Network and click Next.
  3. Leave the format on iCalendar (ICS), paste the https address, then name the calendar and finish.

Official guide: Mozilla Support — creating a new calendar

GNOME & the terminal Linux

GNOME Calendar can't subscribe to a web feed. On GNOME, use Evolution instead: File → New → Calendar, choose the On the Web type with the iCalendar format, and paste the URL.

If you keep your schedule in the terminal, vdirsyncer mirrors the feed to disk and khal reads it. In ~/.config/vdirsyncer/config:

[pair wg]
a = "wg_local"
b = "wg_remote"

[storage wg_local]
type = "filesystem"
path = "~/.calendars/wg/"
fileext = ".ics"

[storage wg_remote]
type = "http"
url = "https://www.chaoss.community/calendar/wg-software.ics"

Then run vdirsyncer discover && vdirsyncer sync (from a cron job or systemd timer to keep it fresh) and point khal at ~/.calendars/wg/.

If events don't show up

  1. Check that you pasted the full address, with no trailing space after .ics.
  2. Confirm the new calendar is toggled visible in your app's calendar list.
  3. Wait out the sync interval — Apple follows the auto-refresh you picked, Google checks about once a day, and Outlook and Thunderbird re-fetch on their own schedules.
